# Changelog

## 1.1.0

Adds drag-and-drop and ordered Kanban; dependency protection; top-three daily planning; a weekly calendar; advanced recurring schedules; reusable project templates; estimates versus recorded sessions; typing autosave, recoverable drafts, and note history; opt-in Windows global capture and reminders; encrypted backup exports; automatic local backups with retention; restore previews; Dari/Pashto core controls and RTL layouts. Includes refreshed media and additional automated and browser checks.

Existing databases are extended in place and version 1 backups remain readable. New backups use version 2. Live databases and automatic backups remain unencrypted; encryption is an optional export format.

## 1.0.0

First release: projects, four-state task board, recurring tasks, priorities, deadlines, checklists, tags, agenda, Markdown notes, persisted focus sessions, daily intentions, activity review, quick find, preferences, exports, validated restore, reversible trash, and a separate sample workspace. Includes tests, actual screenshots, an animated walkthrough, and Windows packaging.
